How every number on this page is computed
  • Source of all numbers: this page downloads data/history.csv and recomputes everything in your browser each time it loads. Nothing is precomputed, so the page changes as the history grows.
  • Run vs session: a run is one daily collection (the date column, UTC). A session is one market trading date (the price_date column). Weekend and holiday runs repeat the previous session's quotes, so each (ETF, session) pair is counted once, using the latest run that reported it.
  • Returns: (latest price − first price) ÷ first price, using each ETF's first and latest session.
  • Daily moves: the pct_change column, the source's own percent change versus the previous close.
  • Missing values: an empty cell is skipped, never treated as zero. If a day's download failed, that day is simply missing from the history.
  • Limits: a short history says little about the long run. This is a class project using delayed public quotes, not investment advice.

CreditScope is a class project that collects public quotes from Nasdaq once a day. Prices are delayed and for information only; this is not investment advice. Change is measured against the previous run; on weekends and market holidays the source repeats the last trading session, so values stay unchanged.

About the platform

An investment research and analytics platform, built from scratch

CreditScope started as an automated daily tracker of twelve stock and bond ETFs. It has grown into a small research platform: a data pipeline, security and company research, side-by-side comparison, and private portfolio analytics, with every calculation checked against an independent implementation.

What you can do here

Today, Browse, Trends

The original tracker: twelve ETFs collected every day by a GitHub Actions pipeline, with raw files, a rebuilt history, a daily GitHub Issue and an installable, offline-capable site.

Explorer

Search securities and see return, volatility, drawdown and a comparison with SPY, always labelled price return or total return.

Fundamentals

Revenue, profit, margins, balance sheet and cash flow from SEC filings, each figure linked to its filing, with growth and profitability ratios.

Compare

Two to six securities over exactly the same dates and basis: growth of 100, volatility, beta, drawdowns, correlations; and company fundamentals side by side.

Portfolio

A transaction ledger with cost basis, unrealized gains, allocation, time-weighted return against SPY, risk and concentration. Real holdings stay private; this page shows a simulated one.

What makes it different

  • Independent validation. Every financial calculation (returns, volatility, drawdown, beta, time-weighted return, ratios, comparisons) exists twice, in JavaScript for the browser and in a separately written Python reference, and automated tests require them to agree to within rounding. Hand-computed cases check the specification itself.
  • Honest about data. Simulated data is labelled everywhere it appears. Price return and total return are never mixed. Missing data produces a blank and a notice, never a made-up number.
  • Privacy by design. Real holdings and API credentials never enter the repository or the public site: they live in a private folder on the owner’s computer and are served to localhost only. No brokerage is connected and nothing can place a trade.
  • Licensing-aware. Market-data providers restrict public display on free plans, so real prices are used privately and the public site uses simulated prices. The only real public data is from the SEC, whose filings may be reused.

The site is plain HTML, CSS and JavaScript hosted on GitHub Pages. There is no server and no database; nothing you type is sent anywhere. The daily job rebuilds its history only from the stored raw files, opens a GitHub Issue each day, and a test suite runs on every push.

How the numbers are calculated

Each page has a “how this is computed” section. In short:

  • Returns: closes are split-adjusted, not dividend-adjusted. Price return = change in close; total return reinvests dividends on the ex-date: TRIt = TRIt−1 × (Closet + Dividendt) ÷ Closet−1. Annualized only for windows of a year or more: (1 + R)365.25/days − 1.
  • Risk: volatility = sample standard deviation of daily returns × √252; maximum drawdown with peak, trough and recovery dates; beta = covariance ÷ benchmark variance; correlation from the same returns. Minimum observation counts apply (20 and 60).
  • Portfolio: time-weighted return chains daily returns after removing deposits and withdrawals (assumed at the close, an approximation); Modified Dietz weights flows by time invested; value change, contributions and investment gain are shown separately because a balance change is not a return.
  • Fundamentals: growth, margins, return on equity and assets, debt-to-equity, free cash flow and CAGR, blank whenever a denominator is not positive.

Limits and honest caveats

  • Educational project, not investment advice. Historical statistics do not predict the future.
  • Public prices on the research pages are simulated. Real prices from a free data account may come from a single exchange (IEX), so their volume is not market volume and is not shown.
  • Fundamentals cover annual reports and standard accounting tags only; foreign filers and company-specific tags are not included. Ratios are not adjusted for acquisitions, inflation or one-off items.
  • The portfolio model excludes taxes, tax lots, options, short positions and foreign currencies.
  • Daily data only; no intraday prices or real-time quotes.

Testing

More than three hundred automated tests run on every push: pipeline and conversion tests for the original tracker; reducer, client and security tests for the SEC and private-data code; browser-independent calculation tests in Node; and cross-language agreement tests between each JavaScript calculation and its independent Python reference. Privacy tests scan the repository for credentials and personal data and check that private paths are ignored and never cached.

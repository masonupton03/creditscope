      How these numbers are computed (and what “adjusted” means)

      Prices: split-adjusted, not dividend-adjusted

      The closing prices in this tool are split-adjusted (a 4-for-1 split does not look like a 75% crash) but not adjusted for dividends. Dividends are kept separately as cash amounts on their ex-dividend dates. Many websites show a “dividend-adjusted close” instead; that bakes reinvested dividends into the price. Here the two are never blended.

      Price return vs total return

      Price return is only the change in the closing price. It ignores the cash a holder receives and understates what an investor earned on dividend payers. Total return assumes each dividend is reinvested in the same security at the close of its ex-dividend date:

      TRIt = TRIt-1 × (Closet + Dividendt) ÷ Closet-1

      Taxes, fees and withholding are ignored. A dividend whose ex-date is not a trading day is credited to the next trading day. Total return is shown only when a security’s dividend history is known. When it is not, every return for that security is labelled Price return (excludes dividends), and you should expect it to understate the true result for dividend payers. When you compare against SPY, both sides use the same basis: if either lacks dividend data the comparison switches to price return for both and says so.

      Period returns

      A period starts at the last close on or before its calendar start date (1M = one month before the latest date, YTD = the last close of the previous year, MAX = the first available close). If the history is shorter than the period, the start is clipped and a notice says so.

      Return = Levelend ÷ Levelstart − 1

      Annualized return

      The compound annual growth rate, shown only for windows of at least one year, using calendar days:

      CAGR = (1 + Return)365.25 ÷ days − 1

      Annualized volatility

      The sample standard deviation of daily returns (between consecutive trading dates in the window) multiplied by √252, the usual number of trading days in a year. It needs at least 20 daily returns. It measures how much the return fluctuates, not the direction.

      Maximum drawdown

      The largest fall from a running peak to a later low, measured on the same basis as the return. The peak, trough and recovery dates are shown; “not yet recovered” means the level has not returned to the old peak. Values within a rounding tolerance count as ties and the earliest wins.

      Drawdownt = Levelt ÷ max(Levels ≤ t) − 1

      Volume

      Shares traded per day, unadjusted. Average dollar volume is the average of close × volume. Missing days are skipped, not treated as zero.

      Comparison with SPY

      Only dates on which both securities traded are used. Returns are measured between consecutive shared dates; beta is the covariance of the two return series divided by the variance of SPY’s, and correlation is their correlation coefficient. Both need at least 60 overlapping returns. Excess return is the security’s cumulative return minus SPY’s over the same window, in percentage points. These are historical statistics, not predictions.

      Data and limits

      Everything is computed in your browser from the series files; nothing is sent anywhere. This is an educational tool, not investment advice, and past performance does not predict future results.

      CreditScope is a class project that collects public quotes from Nasdaq once a day. Prices are delayed and for information only; this is not investment advice. Change is measured against the previous run; on weekends and market holidays the source repeats the last trading session, so values stay unchanged.

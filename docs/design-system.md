# Design system and UX decisions

Goal: look like a credible financial analytics product (the clarity of Linear, the information density of Koyfin, copying neither),
not a class project. Everything here lives in `assets/css/site.css` (shared), `explorer.css` (research pages) and `portfolio.css`.

## Principles

1. **Most important first, the rest on request.** Each page has one primary focus; advanced metrics sit in expandable panels
   ("More metrics", "Risk and drawdown detail", "Return versus change in account value", "Transactions").
2. **Structure through space and hairlines, not boxes.** Key figures are one flat strip with dividers; sections are separated by
   whitespace. Panels (a thin border) are used only for charts and tables.
3. **One accent, colour that means something.** Neutral surfaces and a single blue for links, focus and selection. Green and red
   mean gain and loss; amber means *simulated data or a warning*. Nothing is coloured for decoration.
4. **Sentence-case labels, tabular numbers, true minus signs.** No uppercase letter-spaced labels. One formatter per kind of
   value (`CS.money`, `CS.pct`, `CS.dec`, `CS.date`); a missing value is always "—", never blank, 0 or "N/A".
5. **Honest labels stay visible.** Every page that shows simulated data has a one-line amber notice linking to "About the data";
   the security header carries a "Simulated" tag; data freshness is a line under the title ("Updated 6 h ago", "prices through …").

Type: system UI stack (Inter first if installed, no web-font download), 14.5 px base; page title 24 px, section 15–16 px,
labels 12–13 px. Spacing scale 4/8/12/16/24/32/48. Container 1120 px, 32 px page gutters (16 px on phones).

## Charts

* The categorical colours are the validated order (blue, orange, aqua, yellow, magenta, green) from the data-viz palette; the
  validator passes on both of this site's surfaces (adjacent colour-blind separation ≥ 8.4, normal-vision ≥ 19). In light mode
  aqua, yellow and magenta are below 3:1 on white, so every multi-series chart has a legend and a data table beside it.
* The subject is blue, the benchmark (SPY) is neutral grey, so "us versus the market" reads at a glance.
* Maximum six series on the comparison chart. The Trends ETF chart uses six colours for twelve ETFs: stocks are solid lines,
  bonds are dashed.
* Thin lines (2 px), no markers on dense series, recessive grid, 12 px labels, fewer axis ticks on phones, tooltips with the
  surface colour. All chart defaults come from one function, `CS.chartDefaults()`.

## Navigation

Three areas, one bar: **Markets** (Today, Browse, Trends: the assignment pages), **Research** (Explorer, Fundamentals, Compare)
and **Portfolio**. The tabs for the current area sit under the bar. About is a quiet link on the right and in the footer.
Generated by `scripts/sync_nav.py`; `tests/test_site.py` and `tests/test_pages.py` fail if any page drifts.
Cross-page links keep the ticker (Explorer, Fundamentals, Compare), and a link is shown as "n/a" with a reason when the target
has no data for that ticker.

## Tradeoffs I made (and why)

| Decision | Tradeoff |
|---|---|
| Trends findings sit beside their chart on wide screens; "Why it matters" is collapsed | Required explanation, numbers and "how it is computed" stay visible (the rubric asks for them); the extra commentary is one click away. The page is still long on a phone because the assignment requires four full findings. |
| "Source status" shows all 12 sources as one quiet line of dots, not tiles | Every source's status remains visible (required); per-source row counts moved into the tooltip. |
| Primary stat strips show 4–5 figures; beta, correlation, volume, yield and fees are one click down | Less immediate detail for analysts, a much calmer first screen. Nothing was removed. |
| Amber is reserved for "simulated" and warnings, so the brand has no warm accent any more | The logo and icons are blue; the old amber/green crosshair identity is gone. |
| No web fonts or icon libraries | Slightly less distinctive typography, but zero new dependencies, instant load and full offline support. |
| Light-theme colours were darkened for AA contrast | Light mode is a little more muted than before, including on the three assignment pages. |

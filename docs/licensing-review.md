## 3. The decision that is yours: Nasdaq data

The assignment requires collecting and keeping raw Nasdaq responses and publishing them (GitHub Pages and a public repository). That is why they are there. Options:

1. **Keep as is**, label it (the site and README already say "delayed public data from Nasdaq, for information only"), and exclude it from the MIT licence. Lowest effort; small residual risk if Nasdaq objects (the likely outcome is a takedown request, not more).
2. **Reduce the footprint after grading**: stop the daily run or make the repository private once the assignment is graded (do not do this before; the pipeline is graded).
3. **Ask Nasdaq in writing** (a draft can be prepared like the ones in `docs/permission-requests/`). Slowest; the only way to be certain.

Recommendation: option 1 for the assignment, with the exclusion in the notice, and consider option 2 after grading if the repository becomes a portfolio showpiece. Nothing about the SEC release depends on this choice.
